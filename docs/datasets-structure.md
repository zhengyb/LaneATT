### LaneATT对标签的预处理
- 过滤高度小于 min_lane_height(20) 的车道线;
- 过滤包含少于 min_markers(2) 个标记的车道线;
- 修复车道线名称: 按原始标记区分左右车道线集合，然后按顺序重新命名车道线。（到这里可能会标错l0或r0）
- 过滤图像坐标系上的水平车道标记和垂直车道标记；
- 将车道线上最近的一个标记线性延伸到图像底部；
- 对车道线作线性插值，得到车道线的(x, y)像素坐标系列，y为[y_start, y_bottom], step为1个像素。
- 补齐[l1,l0,r0,r1] 4条车道线；从左到右
- 转换成LaneATT标签：
  - 过滤掉少于2个点的车道线；
  - 重新排序车道线采样点，y从大到小排列（从图像底部向上）
  - 对同一条车道线，过滤y重复的点（数据集标注错误？ 车道线弯曲？）
  - 归一化到(360, 640)
  - 创建固定的LaneATT车道线标签数据， shape为(max_lanes, 77)
  - 统一采样车道线：y[360, 355, 350 ... 0], 3次样条插值，图像底部线性外推；

### Eval Metrics
- 对prediction的处理：
  - 将pred转换成原始图像尺寸的(x, y)坐标序列，y[717, 0], 并转换成字符串，每个image对应一个pred文件。
- 对label文件预处理：
  - 同上述预处理；
  - 截掉y为 [0, 300]的坐标点。注意这个处理!!!
- 计算metric：
  - 对预测的车道线坐标点序列进行插值，统一为更平滑的50个坐标点。在interpolate_lane函数中实现。注意，在推理时是否需要这个处理。
- 计算IoU：
  - 在形状为[1276, 717]的黑白图上画出pred和anno车道线，只提取车道线像素点。
  - 计算iou
- 取iou大于0.5的为tp，并计算fp和fn

### LaneATT对标签的预处理
- 车道线采样坐标点(x, y), y为[160, 710]范围，仅保留有效的x；
- 转换成LaneATT标签：
  - 过滤掉少于2个点的车道线；
  - 重新排序车道线采样点，y从大到小排列（从图像底部向上）
  - 对同一条车道线，过滤y重复的点（弯曲的车道线弯曲或水平的车道线）
  - 归一化到(360, 640)
  - 创建固定的LaneATT车道线标签数据， shape为(max_lanes, 77)
  - 统一采样车道线：y[360, 355, 350 ... 0], 3次样条插值，图像底部线性外推；


### Eval Metrics
- 把预测的车道线按照tusimple的h_sample进行采样。保存成tusimple格式的json文件。
- Metrics:
  - Accuracy: 匹配准确率，对真实车道线上的每个采样点进行匹配，x偏差小于阈值的认为匹配中，统计采样点的匹配率为该车道线的匹配率。匹配率超过85%才算匹配到车道线。对于标注了超过4条车道线的样本，只统计匹配率最高的4条线。
  - FP: 误报率，所有没有匹配中的pred都算误报。
  - FN: 漏报率，所有没有匹配中的gt都算漏判（最多只考虑4条gt lane）
